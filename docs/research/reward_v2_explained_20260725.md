# v2 Reward 详解(默认包)— 2026-07-25

**地位**:v2 是默认(`reward_pack` 缺席即 v2;`reward_pack=v1` 显式兜底,老配方必须声明才能渲染)。数值为名义档(§2 公式代入),probe 校准后冻结 prereg。设计依据:[reward_redesign_20260725.md](reward_redesign_20260725.md)(蓝图+论文对照+定权公式),现状盘点:[reward_audit_20260725.md](reward_audit_20260725.md)。

**记账口径**:每步 reward = Σ_项 weight × value × dt,dt = 0.02 s(50 Hz 控制);weight=0 的项被整个跳过。one-shot 项在触发那一步一次记满。

## 1. 变量名词典(不说明就看不懂的都在这)

| 变量 | 是什么、怎么算 |
|---|---|
| `q` / `q_des`(`processed_actions`) | 实际关节角 / 策略的目标关节角。策略输出经 affine(×scale+默认姿态)+ soft-limit clamp 后交给 PD 的就是 `q_des`。**qbar 罚的是 `q_des` 不是 `q`**(在 clamp 咬合之前给梯度)。 |
| `tts`(`time_to_strike`) | 距击球时刻的秒数。planner 谱系下 = 任务期限时钟:随时间每步 −0.02,**触球后钉在 0**(obs/critic 读它,期限语义)。 |
| `_planner_truth_tts_signed` | tts 的带符号孪生时钟:同源递减但**不截断**,触球后转负。只喂击球窗掩码——窗在 +0.12 s 如约关闭(07-25 C1 修复;修复前窗从触球开到 clip 收尾)。 |
| `strike_window` / `_pos` / `_wide` | \|tts_signed\| ≤ 0.12 s 的布尔掩码。分窗:位置用紧窗、拍面/拍速用宽窗(SMASH 同款不对称)。 |
| `exact_strike` | \|tts\| ≤ 半个控制步的那**一步**,带一拍锁存(`_exact_fired`)——每拍最多触发一次。 |
| `vb_fired`(capture 门) | exact_strike ∧ 拍面正确半球 ∧ 拍位误差 < 9.5 cm ∧ 沿拍面法向的进拍速 > 0.3 m/s。"真打上了"的判据,一拍一次。 |
| `pre_strike` | tts > 0(击球前)。racket_progress 只在这段付钱。 |
| swing-through point | `target_pos − target_vel × tts`:把目标点沿目标速度倒推 tts 秒——拍心贴着"穿击线"走,位置奖顺带管了时机。 |
| `projected_gravity_b_xy` | 重力方向在机体系的水平分量,站直=0,倾斜越大范数越大。upright 类项都用它。 |
| σ(各核的 `std`) | exp 核宽:`exp(−误差²/σ²)`。σ 大=远处也有梯度但不精,σ 小=精但远处梯度死(≈3σ 外没梯度)。 |
| adaptive sigma | 每 500 步:σ ← clamp(exact-strike 误差的衰减均值, σ_min, σ_max)。误差大→核宽(有梯度),误差小→核窄(要精度)。v2 三通道:位置 [0.075, 0.20]、速度 [0.5, 1.0]、**拍面 [0.262, 0.52]**(07-25 新增)。strike_success 的三个 σ 同步联动。 |
| ρ(达成度) | 某个核当前的平均取值(0~1),"这项现在实际挣几成"。 |
| `I` / `B` / `T_c` / PSE | 记账符号:模仿每步上界 I=Σ权重=5;一次性奖金 B;每拍周期步数 T_c≈100;PSE=每步等效收入,one-shot 的 PSE=B×命中率/T_c。 |
| `in_contact` | 脚部接触力范数 > 10 N。脚部各项和 hit_unstable_support 都用这个判据。 |
| `margin_eff`(qbar) | 每关节有效罚带 = min(0.08, 默认站姿距软限的归一化距离 − 0.005)。站姿豁免:设计站姿本身零罚零梯度(双肩 roll 硬限位不对称问题的修法)。 |
| `env_origins` | 每个并行环境的原点(x,y,z);粗糙地形下 z 骑在地形上,虚拟球台/目标/参考全都相对它,所以整个世界一起抬。 |
| mean-over-bodies | 模仿核先对每个身体件算误差平方和,再对身体件取均值进 exp——**加身体件=核变难**(v2 全身 13 件比 v1 上身 7 件难,同权重下收入更低,预算按人数换算过)。 |
| 相对位置(motion_body_pos) | 参考动作的身体件位姿先重锚到**当前躯干系**(T_anchor·T_ref_anchor⁻¹·T_b):比"手相对躯干在哪",不管机器人走到世界哪里。 |

## 3. 分阶段动态(为什么每一阶段都往正方向走、都站得住)

前提:各阶段**权重从不改**,是"达成度 ρ 与命中率 p 的上升"让收入结构自动换挡(静态权重自带课程)。

### 阶段 A|学动作(从零 → 模仿达成)
**收入长相**:模仿 0→~2.7/步(I=4.5×ρ_I,RSI 让机器人出生在参考上,exp 核第一步就有梯度)+ upright_exp 0.5→0.9/步。击球组≈0(窗都够不到,capture 从不 fire),上台组=0。
**为什么向正**:总收入≈3.5/步 全部来自"像老师+站得正";罚项被预算规则钉死(早期分母=模仿收入,f≈0.15,action_rate 带值 clamp → 最坏单帧罚≤2.0)——**净流恒正,死了 V=0 反而亏**,v1 的"自杀区间"(随机初始化下 action_rate 一项 −12/步 → 摔死最优)被 clamp+收入型站正双保险解掉。
**为什么平衡**:平衡不是靠税压出来的——upright_exp 是工资(想挣钱必须站正),全身模仿本身在教"参考的腿就是会站的腿",0.7 rad 摔倒线托底。

### 阶段 B|学击球(首次进窗 → capture 稳定)
**收入长相**:racket_progress(10)是窗外唯一稠密梯度,把拍往目标送每厘米都付钱;进窗后 pos/vel/normal 核在 σ_max(0.2/1.0/0.52)宽容,挥得糙也有梯度;**第一次 capture 得 850**——按 p 从 0→0.7,capture 的每步等效收入从 0 涨到 ≈6/步,**自动超过模仿的 2.7**,探索被强烈导向"打上"而不是"打得像"(SMASH 教训的反面:σ 固定太紧时策略会塌缩回纯模仿)。σ 随误差收紧,精度要求跟着水平走。
**为什么向正**:排序翻转是算术自动的(PSE=B·p/T_c 单调于 p),不改任何权重;窗恒开病已修——位置项在触球后关闭,**不再奖励停拍**,速度项在触球瞬间奖满速、随挥段模仿全权重教完整收拍(挥穿而不是减速,和人学球一样)。
**为什么平衡**:hit_unstable_support 只在窗内罚"单脚击球"这一件事;全程全身模仿持续供给支撑姿态;挥拍冲量的平衡由参考动作自身的设计承担(老师的动作本来就是站得住的)。

### 阶段 C|学上台(capture 稳定 → 合法落台)
**收入长相**:capture 后 virtual 三项激活:过网核先爬坡(故意不用合法门,防 0.2% 合法率下饿死),落点核 σ=1.0 把球往台心拉,全合法再发奖金;同时质量三核 σ 收到验收档(0.075/0.5/0.262)。
**为什么向正**:**"打得准"与"上台"是同一个梯度**——题库的拍速/拍面就是从期望落点反解出来的,窗内质量核(每步 dense)是落点的密集代理,virtual 项(每拍)是稀疏验证,两层方向一致不打架;spin minimize 奖保守控球,现阶段不奖险球。
**为什么平衡**:出手质量核要求触球瞬间拍速矢量可控——靠甩全身换拍速的解在 vel/normal 核上天然低分;窗内单脚罚+全程模仿兜底。

### 阶段 D|学移动(未来轴,现在是隐式的)
**现状**:base-free 设计里没有"移动奖励"——racket_progress 就是全身跑位发动机(腿、腰、臂都为"把拍送过去"挣钱),站位远的题自然逼出步伐;粗糙地形 + 单侧 clearance 塑形抬脚。
**显式化候选**(散点题库/canonical 库成熟后):HITTER 式击前 base station 加法项(击后关闭,放它去下一球)——注意是**加法激活**不是全程钉底座(v1 删 base_position 的教训);mjlab 速度跟踪为备选参照。
**为什么平衡**:摔倒线 + 合并采样的 push DR + 全身模仿的步态先验;真到大范围移动臂,再按 mjlab 把 foot 组(air_time/swing_height)按指令门控接回来。
