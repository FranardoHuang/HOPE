## 1. 一句话战略定位

**Stage 1 要证的一句话没变**:给策略看题目(拍面指令观测)+ 给物理可行的反解答案当训练目标 +
奖励按答案付钱,固定点无旋球就能打回去(判据:MuJoCo 考卷回球率 ≥50%)。

**现在到哪**:方向已被**入账级证据钉死为真**,但胜利是"用健康底片(v4)拿到的",不是用我们真正
想要的专业动作源(v5)拿到的。所以 Stage 1 现在同时握着两件事——
- **一个已经成立的配方**(题库+拍面指令观测+奖励锚指令+腕不抄录像),正手 0→0.75、反手用 v4
  底片翻身入账;
- **一个还没打赢的攻坚**:让 v5(专业/激进动作)也能被训练,这决定"专业动作训练"这条路线的生死。

三天最大的位移不是多跑了几个臂,而是**把 Stage 1 从"调 reward 的实验"重写成了"造一条普适管线的
实验"**:反手病根被从黑盒拆成四层可修机制,顺带逼出了"参考=路径不是轨迹"的第一性原理,管线蓝图
成形。**收官只差最后一程:用 TOPP/逆动力学预算把 v5 追平 v4。**

## 2. 核心叙事线(三天科学主线)

### ① 反手病根:从"黑盒一句话"拆成四层可验证机制,逐层治愈

07-08 之前我们对反手只有一个黑盒结论:"v5 反手参考本身不可平衡执行"(15.5 rad/s²=hopex 6 倍)。
这句话正确但没用——它不告诉你修哪、怎么修、修没修对。三天做的核心科学工作,是把这个黑盒拆成
**四个可测量、可独立验证、可分别修复**的机制。**它们不是四个病,是同一个"遮挡幻觉"病根的四处发作**:

| 层 | 机制 | 证据(可测量) | 修法 | 状态 |
| --- | --- | --- | --- | --- |
| L1 | **GMR IK 冷启动瞬态** | 前 0.12s(6 帧)4 个腿关节参考速度超 URDF 硬限位(hip_pitch −15.5>12.04 等);mink 从直立冷启动爬进深蹲;首帧峰 15.89 rad/s | 帧 0 warm-up 到收敛 → 首帧峰 **15.89→0.81**、超限 5→0、触球峰保留 100.4% | ✅ 源头修完 |
| L2 | **遮挡下尺度错 9%** | GVHMR 逐视频估体型在遮挡下是噪声源,v5 骨盆 0.78 vs v4 0.97m(被估矮 9%) | canonical betas(标准 SMPL 体型只取姿态)→ v5hA | ✅ 首例已成 |
| L3 | **想象腿深蹲** | 腿被球台挡,vitpose 腿部置信 0.07–0.33(肩腕 0.83–0.89);GVHMR 按先验补全深蹲 | 腿移植 v5hL(换同人 v4 健康腿)/ 终态=任务驱动下半身 | 🔬 资产级近似已成 |

**这条线的方法论价值 > 案子本身**:每一层都配了独立取证工具(判炸器 L0 逐关节审位置/速度/加速度、

- "反手是不是热启动闹的?" → **否**,yikang 从零谱系臂(硬植体、8192 环境、同 v5 对)反手摔率 0.97
  比热启臂 0.93 还高,热启无关;
- "遮腿观测能不能救?" → **不能**,R7(只遮腿 × v5rg)fallB 0.819≈M1 0.815、R9b(遮腿+删缰绳 × v5hA)
  eplen 22/摔 1.00 判死——**毒还从终止/RSI 通道进,资产侧修复才是主战场**;
- 滑脚因果链**三次独立验证**(yikang 取证 + franco 侧复测 + oracle 剂量回测互证)。

### ② 由此的第一性原理顿悟(三条,重写了后面所有设计)

反手侦探做到 L4 时,franco 逼出了一个更根本的问题:**我们凭什么要机器人逐帧照抄人的时序?**
由此定案三条第一性原理,它们不是哲学,是**直接改了代码语义和管线结构**的判据:

1. **参考 = 路径(path),不是轨迹(trajectory)。** 人类视频的唯一价值是**协调性路径先验**
   (引拍-挥拍的髋肩次序、挥拍形状),让 31 维探索不必从零发明"人样";它**不是动力学规范**
   ——人的时序绑定在人的质量/惯量/肌肉上,机器人既不需要也不应该复制。视频时序三层各自定去留:
   发力顺序(路径自带,✅自动保留)/ 节奏形状(**真正的开放问题**,A/B 消融正在测)/ 绝对时间刻度
   (人的肉体常数,❌不抄)。

2. **时间律机器人本位重解。** 回球任务的唯一硬约束是**触球瞬间的状态**(拍点 p*、拍面 n*、拍速 v*);
   触球前一切只受机器人自身约束(力矩/速度/平衡)。所以时序由机器人自己解一个单调时间映射 s(t):
   匀加速、逐关节 |q̇|≤URDF×余量、|q̈|≤预算;**不可达就延长加速时间(提前起拍),永不降 v***。
   这一条**连带重写了变速语义**:变速 = 换一个 v* 重解时间律(改的是加速时间),不是全片时间缩放
   (那让 a∝缩放² 全程改变=优化了错误的量)。**平滑问题就地消解**:时间律是我们合成的,天生光滑
   → 时间维平滑构造性成立,只剩空间维去噪(路径本身被重建噪声污染处)。

3. **可执行性 = 力矩 + 接触,不是位置限位。** 这是三天最贵的教训的正名:重定向只保证位置限位合法
   (腕链审计零裁剪),**速度/加速度/动力学可行性管线里从来没人查**——"合法但暴烈"的参考就这么漏进来。
   07-10 oracle 校准把这条钉成数字:①单帧峰值不预测摔(v4rg 正手 172% 尖峰照样 0.02),**预测摔的是
   "不可行时长占比"**(判决从峰值制改剂量制);②binding = **接触可行性为主**(CoP 触球窗前后连续冲出
   脚尖 + 摩擦锥挥拍峰破 1.4–1.5×),力矩侧 binding 是**腰**(roll 127–129%/pitch 130%)**不是髋**。

### ③ 普适管线蓝图成形(终态)

三条原理拼出一条端到端管线,**逐 clip 手术从此定位为过渡补丁,不是终态**:

```
视频 → GVHMR/GMR(帧0 warm-up)→ 上半身路径提取(+空间去噪:曲率×vitpose置信度判定)
     → 下半身任务驱动(站位/蹲深 = 来球函数,不从视频抄)
     → 逐题时间律合成(答案态为边界条件,预算=机器人模型算不是猜)
     → 模型级可行性筛(判炸器 L0 + 逆动力学 oracle 余量)→ tracker 过滤 → 训练
```

关键:**智元文档已扫,所有输入都在**(URDF 逐关节位置/速度/力矩限位 + 连杆惯量 + MJCF frcrange + PD 增益)
——加速度/力矩预算可以从机器人模型**算**,不需要猜;但它**不给**任何轨迹平滑/加速度规范(固件不滤波),
所以这套时间律合成是我们必须自己造的、也是别人没有的。

### ④ 诚实现状:剂量曲线证明方向对,但还没追平 v4

**时间律剂量-响应是本周最硬的一条正向证据**:把反手的可执行加速度预算当剂量,摔率单调响应——
**acc 4.49 → 0.79 → acc 3.50 → 0.48 → acc 2.82 → 0.27**(v5hLt/R9d → v5syn35/R9f → v5syn/R9e)。
这条曲线单调、可预测、有物理解释,**证明"降加速度预算(=机器人本位时间律)确实在治反手摔"这个方向是对的**。

但两个诚实边界必须写在最前面:
- **still 未追平 v4**:v4rg 真腿底片摔率 ~0.01;时间律合成把 v5 从 ~0.79 压到 0.27,**方向对、幅度到 acc≈v4
  水平(2.82)才崩落,但 0.27 仍远高于 v4 的 0.01**。v5 还没被"救回",只是被"救到有戏"。
- **TOPP 是最后一程**:0.27 这个点(acc 2.82,已≈v4 加速度水平)反手仍摔,说明**降全局加速度不是终点**
  ——oracle 定案剩下的 binding 是接触锥 + 腰力矩,**下一程 = TOPP v2 用逆动力学预算(τ=Mq̈+h 盯腰+接触锥)
  精确整形**,而不是继续降 mean|acc|。

## 4. 普适管线 vs 逐 clip 手术(哪些是补丁,哪些是终态)

| --- | --- | --- |
| warm-up(帧 0 收敛) | **终态·修路径** | 保留进管线第一步;源头修完 R-c(i) 的 settle-skip N→0 退役 |

| 强度重定时 v5hLt(R9d) | **过渡·保留作对照臂** | 剂量曲线的高 acc 锚点;终态是 v5syn 一族 |
