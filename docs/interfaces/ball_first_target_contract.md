# 球优先目标契约（ball-first target contract）

**人话**：先有球，再解出"回这颗球需要的拍面和拍速"，最后才处理老师动作去服务这个目标。
反过来做——拿老师自己的速度当目标、再去问能不能回球——会造出**没有任何球能赢的任务**。

Franco 2026-07-26 裁定，并附加总纲：**这些必须做进训练系统、每次自动生效**，不是某一波的补丁、
不是散落在 pod 上的脚本、不是某个 session 记得跑一遍的工序。

## 1. 为什么（一次事故的完整因果）

canonical 五动作波次把顺序做反了，代价是：

- 目标速度框 = 老师在击球帧的拍速 ± (0.5, 0.5, 0.4) m/s，**目标即老师,按构造成立**；
- 但照该速度打，球落在 x ≈ 1.74 m，而网在 **x = 1.87 m**——**差 13 cm 过不了网**；
- 于是奖励里两项对打：速度匹配项要求"打到命令的速度"（球死在网前），上台奖要求"把球打上去"；
- policy 选了上台奖：`strike_vel_pass_exact_backhand = 0.1179`（**88% 的击球"速度不达标"**）
  而 `virtual_return_rate_backhand = 0.8609`。**它学会了故意不听速度命令。**
- 离线复现证实这是唯一活路：按实际挥速倍数扫，×1.0 → 0.150、×1.5 → 0.597、**×2.0 → 0.970**。

**推论(必须写进任何改动的验收条件)**：若把标注速度强制回命令值，反手会从 **0.86 掉回 0.15**。
任何"让 policy 听话"的修法,如果不同时修目标本身,都会摧毁现有成绩。

另一半事故同源:**慢拍速本来是对付快来球的**(短促击球靠反弹取速)。用慢来球去评一个挡球,
等于要求它自己造速度——那不是挡球干的事。**动作与来球必须配对评估**,单一球集评五个动作
会把"配错球"误判成"动作不行"。

## 2. 契约(系统必须保证的三条)

1. **目标由球反解得到,不由老师复制。** 每个来球经 `StrikeSpecPlanner` 的逆解得到需求拍面法向
   与拍速；解不出、过不了网、落不了台的球**不发货**(题库生成器已有此门)。
2. **每个动作声明自己应对的来球档位。** 拉球与挡球的自然来球速度不同,该档位是**逐 clip 的一等
   配置字段**,由训练配置读取,不是文档里的一句话。
3. **不可能的任务在构造时即被拒。** "没有任何球能产生的目标"和"配了不可达成目标的球",都必须
   在环境构造(而非训练几千迭代后)失败封闭。

## 3. 现状与缺口

| 环节 | 该由谁负责 | 现状 |
| --- | --- | --- |
| 采样来球 | `gen_stage1_questions.py`(bank 模式) | canonical 谱系**未使用** |
| 由球反解目标 | `strike_spec_planner.py`(venue 接触+马格努斯链的 LM 逆解) | 同上 |
| 答案自检 | 生成器用训练侧 torch 物理回放每条保留答案 | 同上 |
| 逐 clip 来球档位 | **不存在** | 需新增字段 |
| 击球速度达标 | TOPP 时间律(目标是"路径最短时间",**击球帧速度是副产品**) | 需变成一等要求 |
| 构造期拒收 | `RacketTargetCommand` 构造(G1/G4/G6 已落) | 球-目标一致性门**未落** |

题库不能从 v4rg 谱系搬运:bank 与 clip 的 SHA-256 内容绑定
(`mdp/stage1_question_bank.py: validate_runtime_motion_contract`)。所以 canonical 必须**自己生成**。
"canonical 题库生成"此前挂在队列上当锦上添花——**按本裁定它是关键路径**。

## 4. 系统化落点(每条都要能自动生效)

- **题库生成进标准工序**:`run_motion_clip_to_training_binding.md` 增加"生成本谱系题库"一步,
  其输出是绑定的必填字段;没有题库的谱系不得进入评分波次。
- **逐 clip 来球档位**成为绑定 manifest 的必填字段,并由环境构造校验(缺失=拒)。
- **击球速度**从 TOPP 的副产品变为约束或排序项;编译收据须记录"该 clip 在击球帧交付的拍速"
  与"合法回球所需拍速"的比值。
- **一致性门**:环境构造时,对每个 clip 校验"命令目标在其声明的来球档位下存在合法回球",
  零则拒绝启动(与 G1 同级)。
- **抓拍解算(grip)**:未解算 grip 的 clip 应当**拒绝进入管线**,而不是静默 `--grip off`。
  老谱系把解值放在 `cfg/strike_annotations.yaml` 的 `grip:` 块(`solve_grip_blade.py` 求解)。
